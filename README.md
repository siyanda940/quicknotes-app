# QuickNotes

QuickNotes is a simple note-taking web app that lets users create, organise, search and delete notes. Notes can be assigned to Personal, Work or Study categories, and they are saved in the browser so they remain available after refreshing the page.

## Features

- Add notes with a category
- Personal, Work and Study categories
- Delete individual notes
- Search notes
- Case-insensitive searching
- Validation for empty notes
- Validation for notes over 200 characters
- Displays the correct number of notes
- Saves notes using localStorage
- Loads saved notes after refreshing the page
- Responsive layout for smaller screens

## How to Run Locally

1. Clone or download the repository.
2. Open the `quicknotes-app` folder.
3. Open `index.html` in a web browser.
4. Start adding notes.

No additional software or dependencies are required.
